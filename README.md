# landingviper

Dynamic Landing Page and Web Server written **100% in NextViper** (`.nv`), developed and maintained by **Nuratix LLC** ([https://nuratix.com](https://nuratix.com)).

---

## 🚀 How to Run

### 1. Using `nextviper` CLI

```bash
# Clone the repository
git clone https://github.com/nuratix/landingviper.git
cd landingviper

# Start the local server
nextviper run server.nv
```

### 2. Using `npx` (No Global Install Required)

```bash
npx nextviper run server.nv
```

### 3. Open in Browser

Navigate to **[http://localhost:8080](http://localhost:8080)** or `http://127.0.0.1:8080`.
